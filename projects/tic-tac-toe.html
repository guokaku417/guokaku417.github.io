Tic-Tac-Toe

C
GitHub 仓库

项目简介

本项目基于 C 语言实现经典的三子棋（Tic-Tac-Toe）游戏，支持两名玩家在 3x3 棋盘上轮流落子，率先在横、竖、斜任意方向上连成三子者获胜。代码结构清晰，逻辑完整，适合 C 语言初学者学习数组操作、函数封装和游戏逻辑设计。

核心功能

  • 棋盘初始化 — 使用二维数组表示棋盘，支持动态重置
  • 落子判定 — 检查目标位置是否已被占用，确保合法落子
  • 胜负判断 — 每步落子后自动检测横、竖、对角三线
  • 平局检测 — 棋盘填满且无胜者时判定为平局
  • 棋盘打印 — 简洁直观的控制台输出，玩家轮流提示

项目结构

  • main.c — 主程序入口，游戏循环
  • board.h — 棋盘操作函数声明
  • board.c — 棋盘初始化、打印、胜负判断实现
  • player.h — 玩家操作函数声明
  • player.c — 落子逻辑实现

编译与运行

gcc main.c board.c player.c -o tic_tac_toe
./tic_tac_toe
