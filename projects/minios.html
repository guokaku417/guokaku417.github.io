MiniOS

CAssembly
GitHub 仓库

项目简介

MiniOS 是 x86 架构上的微型操作系统内核课程设计项目，实现了从引导加载到进程调度的完整内核功能。项目涵盖操作系统核心概念：中断处理、内存管理、进程调度和文件系统，代码量约 3000 行。

系统架构

🖥️

进程调度

基于时间片轮转（RR）调度算法，支持多任务并发执行

💾

内存管理

分页内存管理，支持虚拟地址到物理地址的映射

📁

文件系统

简易 FAT 文件系统，支持文件的创建、读写、删除

核心功能

  • 引导加载（Bootloader） — 从磁盘加载内核到内存，进入 32 位保护模式
  • 中断处理 — 实现 IDT 和中断服务例程，支持键盘等外设中断
  • 进程管理 — PCB 管理、进程创建与销毁、进程状态转换
  • 系统调用 — 提供 print、read、exit 等用户态系统调用接口

构建与运行

# 安装依赖（Ubuntu）
sudo apt install nasm qemu-system-x86 gcc

# 构建内核
make all

# 在 QEMU 中运行
make run
