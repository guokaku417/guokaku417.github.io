CSAPP 读书笔记：深入了解计算机系统

2026-04-10 · 15 分钟

CSAPP（Computer Systems: A Programmer's Perspective）是计算机系统方向的经典教材。本文分享我在阅读过程中的核心收获，从信息的表示到程序的机器级表示，带你俯瞰计算机系统的全貌。

一、信息的表示

计算机中所有的信息——数字、文本、图像、指令——都以二进制表示。这看似简单，但其中有很多容易被忽视的细节。

整数表示

大多数编程语言中的整数使用补码表示。补码的好处在于加法和减法可以使用同一套硬件电路。理解补码需要记住：最高位的权重是负的。

// 无符号整数的最大值
unsigned char a = 255;  // 0xFF

// 有符号整数的最大值
signed char b = 127;   // 0x7F

// 有符号整数 -1 的表示
signed char c = -1;    // 0xFF（和 255 的位模式相同！）

这就是为什么当把 -1 赋值给 unsigned int 时会得到一个非常大的正数——位模式没有变，但解释方式变了。

二、程序的机器级表示

编译器将 C 代码翻译为汇编指令，汇编器再将汇编指令翻译为机器码。理解汇编能帮助我们写出更高效的代码。

寄存器与栈

// 一个简单的 C 函数
int add(int a, int b) {
    return a + b;
}

// 对应的 x86-64 汇编
add:
    push   rbp
    mov    rbp, rsp
    mov    DWORD PTR [rbp-4], edi   ; 参数 a
    mov    DWORD PTR [rbp-8], esi   ; 参数 b
    mov    eax, DWORD PTR [rbp-4]
    add    eax, DWORD PTR [rbp-8]
    pop    rbp
    ret

三、存储器层次结构

理解存储器层次结构是写出高性能程序的关键：

  • 寄存器 — 速度最快（1 个时钟周期），容量最小
  • L1 / L2 / L3 缓存 — 速度逐级递减，容量逐级增大
  • 主存（RAM） — 速度较慢（约 100 个时钟周期）
  • 磁盘 — 速度极慢（约千万个时钟周期）

缓存友好的代码模式：

// 缓存友好：按行遍历（空间局部性好）
for (int i = 0; i < N; i++)
    for (int j = 0; j < N; j++)
        sum += a[i][j];

// 缓存不友好：按列遍历（每次访问都跨越行）
for (int j = 0; j < N; j++)
    for (int i = 0; i < N; i++)
        sum += a[i][j];

四、链接

链接是将各个目标文件合并为可执行文件的过程。理解链接能帮助你解决编译时的"未定义引用"和"重定义"错误。

关键概念：

  • 符号解析 — 将每个符号引用关联到一个符号定义
  • 重定位 — 为每个符号分配运行时地址
  • 静态链接 vs 动态链接 — 静态链接将库代码复制到可执行文件中；动态链接在运行时才加载共享库

五、总结

CSAPP 的每一章都值得反复阅读。它不仅教会你计算机系统的工作原理，更重要的是培养你从系统角度思考问题的能力——这对写出高效、可靠的代码至关重要。
