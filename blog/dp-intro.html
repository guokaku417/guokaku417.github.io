动态规划入门：从斐波那契到背包问题

2026-05-01 · 8 分钟

动态规划（Dynamic Programming, DP）是算法面试中的重中之重，也是许多初学者感到头疼的难点。本文将从最基础的斐波那契数列开始，带你逐步理解 DP 的核心思想——状态定义与状态转移。

一、从斐波那契数列说起

斐波那契数列的定义非常简单：

# 递归版本 — 直观但低效
def fib(n):
    if n <= 1:
        return n
    return fib(n - 1) + fib(n - 2)

这个递归版本的时间复杂度是 O(2ⁿ)，因为存在大量重复计算。例如 fib(5) 会重复计算 fib(3) 和 fib(2) 多次。这正是动态规划要解决的问题——通过记录已计算的结果来避免重复计算。

二、记忆化搜索（自顶向下）

最简单的优化方式：用一个数组把计算过的结果存起来。

def fib(n, memo={}):
    if n in memo:
        return memo[n]
    if n <= 1:
        return n
    memo[n] = fib(n - 1, memo) + fib(n - 2, memo)
    return memo[n]

时间复杂度降为 O(n)，空间复杂度 O(n)。

三、真正的动态规划（自底向上）

动态规划的核心是从最小的子问题开始，逐步构建到目标问题：

def fib(n):
    if n <= 1:
        return n
    dp = [0] * (n + 1)
    dp[1] = 1
    for i in range(2, n + 1):
        dp[i] = dp[i - 1] + dp[i - 2]
    return dp[n]

这就是动态规划的两个关键要素：

  • 状态定义：dp[i] 表示第 i 个斐波那契数
  • 状态转移方程：dp[i] = dp[i-1] + dp[i-2]

四、背包问题

背包问题是 DP 的经典应用。以 0-1 背包为例：给定 n 个物品，每个物品有重量 w[i] 和价值 v[i]，在容量为 C 的背包中如何选择才能使总价值最大？

状态定义

dp[i][j] 表示前 i 个物品中，选择总重量不超过 j 的最大价值。

状态转移

def knapsack(weights, values, capacity):
    n = len(weights)
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        for j in range(1, capacity + 1):
            if weights[i - 1] <= j:
                dp[i][j] = max(
                    dp[i - 1][j],
                    dp[i - 1][j - weights[i - 1]] + values[i - 1]
                )
            else:
                dp[i][j] = dp[i - 1][j]

    return dp[n][capacity]

五、总结

动态规划的解题步骤可以概括为：

  • 定义状态 — 明确 dp 数组的含义
  • 写出转移方程 — 找到子问题之间的关系
  • 初始化 — 确定 base case
  • 确定遍历顺序 — 保证状态转移的正确性

多刷题、多总结，你会慢慢发现 DP 的美妙之处。
