Python 装饰器：从入门到进阶

2026-03-01 · 10 分钟

装饰器是 Python 中非常强大的特性。本文从闭包概念讲起，逐步深入到带参数的装饰器、类装饰器，以及 functools.wraps 的作用。

一、预备知识：函数是一等公民

在 Python 中，函数与其他对象一样：

  • 可以赋值给变量
  • 可以作为参数传递
  • 可以作为函数的返回值
def greet(name):
    return f"Hello, {name}!"

# 函数赋值给变量
say_hello = greet
print(say_hello("Alice"))  # Hello, Alice!

# 函数作为参数
def call_twice(f, x):
    return f(x), f(x)

print(call_twice(greet, "Bob"))

二、闭包

闭包是指一个函数记住了其外部作用域的变量，即使外部函数已经执行完毕：

def make_multiplier(n):
    def multiplier(x):
        return x * n
    return multiplier

double = make_multiplier(2)
triple = make_multiplier(3)

print(double(5))   # 10
print(triple(5))   # 15

double 记住了 n=2，triple 记住了 n=3——这就是闭包。

三、基础装饰器

装饰器本质上就是一个接受函数并返回新函数的闭包：

def timer(func):
    import time

    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        elapsed = time.time() - start
        print(f"{func.__name__} 执行耗时: {elapsed:.4f}s")
        return result

    return wrapper


@timer
def slow_function():
    import time
    time.sleep(1)
    return "done"

slow_function()  # 输出: slow_function 执行耗时: 1.0004s

四、functools.wraps

问题：装饰后的函数丢失了原始函数的元信息：

print(slow_function.__name__)  # wrapper（不是 slow_function！）

解决方案：使用 functools.wraps：

import functools

def timer(func):
    @functools.wraps(func)
    def wrapper(*args, **kwargs):
        # ... 同上
        return result
    return wrapper

五、带参数的装饰器

有时候我们需要让装饰器接受参数，这时需要再加一层嵌套：

def repeat(times=1):
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            for _ in range(times):
                result = func(*args, **kwargs)
            return result
        return wrapper
    return decorator


@repeat(times=3)
def say(word):
    print(word)

say("Hello!")  # 打印三次 Hello!

六、类装饰器

除了函数，类也可以作为装饰器：

class CountCalls:
    def __init__(self, func):
        functools.wraps(func)(self)
        self.func = func
        self.count = 0

    def __call__(self, *args, **kwargs):
        self.count += 1
        print(f"第 {self.count} 次调用")
        return self.func(*args, **kwargs)

七、装饰器的实际应用

  • 日志记录 — 自动记录函数调用参数和返回值
  • 性能分析 — 统计函数执行时间或调用次数
  • 权限校验 — 检查用户是否有权执行操作
  • 缓存 — 缓存函数的计算结果（如 functools.lru_cache）

八、总结

装饰器的本质是函数的函数——它接收一个函数，返回一个增强后的函数。掌握闭包是理解装饰器的关键，而 functools.wraps 是编写正确装饰器的必备工具。
